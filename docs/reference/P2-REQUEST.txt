==================================================
FUZZY / TYPO MATCHING
==================================================

Implement conservative fuzzy matching using an appropriate library/algorithm.

Do not implement:

highest_score = automatic winner

Require:

- threshold;
- tie handling;
- ambiguity margin/rule;
- hard-negative handling;
- no-confident-match state.

Expose match reason/type, e.g.:

exact_brand
exact_generic
alias
fuzzy_brand
fuzzy_generic

A fuzzy score is only NAME-MATCH similarity.

It is NOT medical or clinical confidence.

==================================================
AMBIGUITY
==================================================

Ambiguity must be a first-class outcome.

Support equivalent structured states such as:

UNIQUE_MATCH
AMBIGUOUS_MATCH
NO_CONFIDENT_MATCH

Ambiguity must be returned for cases such as:

- same brand, multiple strengths;
- same brand, multiple forms;
- generic mapping to many products;
- fuzzy candidates too close to distinguish safely.

Never silently collapse medicine presentations.

==================================================

Never call it:

- driving distance;
- road distance;
- delivery time.

Test radius boundaries.
